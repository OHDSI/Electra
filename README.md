# Electra: Enhanced Library for Evaluation of CohorTs and Review At-scale

The ELECTRA (Enhanced Library for Evaluation of CohorTs and Review At-scale) Interface is an application designed to evaluate, compile, and store phenotypes as a catalog or library. Users can directly evaluate their own cohorts developed in ATLAS, propose a new phenotype to be approved for the library and request the withdrawal of an existing one. Additionally, Reviewers can view the evaluations conducted by the users, directly in the application without running any aditional analyses, and accept, reject or request more information to add the suggested phenotype to the library. 

For an End User's Guide with further details on the functionalities of the application please see the [End Users Guide here](https://drive.google.com/file/d/1FB1e84J-xCJjZKCIz80JArXhzNqe1bon/view?usp=sharing).
For a developer’s guide on how to implement the interface within your setting please see ELECTRA [Developer’s Guide here](https://drive.google.com/file/d/13CzL2Qywf8BeBnf3g6Yq70cw1r-3IgyN/view?usp=sharing).

ELECTRA is part of a broader Phenotype Framework & Library project (see schema below), which includes the Phenotype Framework, to standardize the way phenotypes are created, reused and evaluated; the ELECTRA Interface hosting the library to store and share final (evaluated) phenotypes, and the Phenotype Library, including the evaluated and approved phenotypes as the end-product. 

<img width="940" height="379" alt="image" src="https://github.com/user-attachments/assets/d7116e6c-f8c5-44de-9869-005463a62b02" />

The Phenotype Framework is a process recommended to develop and evaluate phenotypes, standardizing the methodology used and the output delivered. It is based on the state-of-the-art methods used in OHDSI, EMA’s DARWIN, Phecode system and other public phenotype development projects. It is depicted in the figure below and expanded in the document Phenotype Framework available in the link (to be uploaded).

<img width="940" height="535" alt="image" src="https://github.com/user-attachments/assets/5d976ac3-0cc1-40dc-a020-2f70da2b3c8c" />

The ELECTRA interface hosts the evaluated and approved phenotypes as a library with documentation of what is included and what is not included in the phenotype definition and allow users to test, curate and evaluate their own phenotypes and reviewers to track the phenotype revision process, all in a single application.
