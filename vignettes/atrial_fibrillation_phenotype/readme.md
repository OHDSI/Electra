This folder contains the use-case phenotype definition for Atrial Fibrillation generated using Electra. The included files represent all components required to understand, implement, and document the phenotype.

Files included:

- CD_json_data.json — Electra JSON output containing the full cohort definition logic, concept sets, inclusion/exclusion criteria, and temporal constraints.
- CD_LD_data.txt — Clinical and logic description of the AKI phenotype, including rationale, differential diagnosis context, and logic description.
- Citation_data.txt — Authorship and citation metadata for the phenotype.
- clinical_code_list_data.csv — Complete list of clinical codes used in the phenotype.
