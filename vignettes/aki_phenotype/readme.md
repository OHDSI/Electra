This folder contains the use-case phenotype definition for Acute Kidney Injury (AKI) generated using Electra. The included files represent all components required to understand, implement, and document the phenotype.

Files included:
CD_json_data.json — Electra JSON output containing the full cohort definition logic, concept sets, inclusion/exclusion criteria, and temporal constraints. 
CD_LD_data.txt — Clinical and logic description of the AKI phenotype, including rationale, differential diagnosis context, and logic description. 
Citation_data.txt — Authorship and citation metadata for the phenotype. 
clinical_code_list_data.csv — Complete list of clinical codes used in the phenotype.

Reference materials:
* OHDSI_AKI_Phenotype_Poster.pdf — A summary poster describing the AKI phenotype conceptualization, definition, and cross-database evaluation. Access file: https://drive.google.com/file/d/15WJKxWoQUXtOzpT2ikaKQ1sgbMtR5iCz/view?usp=sharing
* Rivera_AKI_phenotype_2023symposium.pdf — A report detailing the methodology, clinical rationale, and CohortDiagnostics results used to evaluate the phenotype. Access file: https://drive.google.com/file/d/1s8DVOd-ZRkfkQofS86HuN3iZoGY5R6Eb/view?usp=sharing
